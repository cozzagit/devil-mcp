# Contribuire

Questo repository contiene la documentazione e gli esempi del server MCP di DeviL; il servizio vero gira su <https://devil.vibecanyon.com>. I contributi più utili sono:

- **Esempi di comandi** che ti hanno funzionato con Claude Code (in `examples/comandi.md`).
- **CLAUDE.md** adattati a casi d'uso diversi (software house, agenzie, consulenti).
- **Correzioni** a documentazione e traduzioni.
- **Segnalazioni e idee** sul server MCP: apri una issue con i moduli «Segnalazione» o «Idea».

## Come proporre una modifica

1. Fai un fork e crea un ramo (`docs/…` o `examples/…`).
2. Scrivi in italiano semplice, frasi brevi, esempi concreti.
3. Non includere mai token, dati di aziende reali o informazioni personali.
4. Apri una pull request spiegando cosa cambia e perché.

Per problemi di sicurezza non usare le issue: vedi [SECURITY.md](SECURITY.md).
